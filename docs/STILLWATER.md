# 雨歇 / Stillwater

主入口是 `scenes/rebirth/Stillwater.tscn`。旧版二维场景和原始素材保留。

## 当前战斗

闪避留下持续 4.5 秒的留影。Q 消耗留影，沿两点之间的路径回锋，对线上的敌人造成伤害和架势压力；建筑阻断路径，回锋不会消耗无效施法的体力。E 破阵踢退正面敌人，撞墙或撞上其他敌人会产生追加伤害，并能反弹飞弹。瞬间正面格挡也能反弹飞弹；近战见切强化下一击。架势打满会露出 2.6 秒破势窗口，靠近按 F 追斩并恢复体力。

直剑均衡；重刃范围大、消耗高，可打断普通敌人，但连续打断有恢复间隔；灵剑更快，命中回复体力，第三段连击释放剑气。敌人蓄势不会被普通轻击无限重置，近战出招会沿锁定方向踏步。多个敌人分批出招，未出招者寻找侧面位置。

攻击输入有约 200 毫秒缓冲；闪避可取消攻击和命中停顿。直剑测试从输入到伤害为 4 个 60 Hz 物理帧，约 67 毫秒；这是引擎判定延迟，不是显示器到输入设备的端到端延迟。重刃、直剑、灵剑拥有不同动作节奏。命中使用短促停顿、短闪、沿真实剑尖采样的剑轨和方向性位移。

## 美术和声音

实时 3D 石院、屋檐、水面、山岩、石灯、枫树、旗幡和雨，使用风化材质、实时阴影、环境遮蔽和 MSAA。战斗镜头收近至普通战斗 13、首领 15.5 的正交尺寸，保留标题远景。

角色已替换为 KayKit 的 CC0 骨骼模型，武器绑在手骨，行走、出剑、格挡、踢击、闪避、受击和死亡使用骨骼动画；程序重新采样出手时序，调整比例与布料配色。兵刃采用有刃脊和收尖的独立几何体。授权来源见 [素材许可](THIRD_PARTY_ASSETS.md)。无图形的 headless 验证不创建调色着色器，规避 Godot dummy renderer 的材质查询错误；原生 Metal 仍完整运行并单独验证这些材质。

循环背景音乐已停用，保留原文件。战斗使用 8 类原创合成音效：出剑、重挥、命中、格挡、见切、闪避、回锋和撞击。声音池限制重复发声，暂停与退出执行统一清理。

## 关卡与操作

三处石灯封印、近战与远程守灯人、地面危险区、两次成长选择，最终迎战具有第二阶段的无相。包含标题、操作指南、暂停、设置、胜败结算。

WASD / 方向键移动，左键 / J 出剑，右键 / K 格挡，Shift / 空格闪避，Q 回锋，E 破阵，R 温酒，F 石灯 / 破势追斩，1–3 换刃，Esc 暂停，F11 全屏。手柄映射保留；尚未完成实体手柄验证。

## 验证

`python3 scripts/tools/run_tests.py` 串行执行 32 个测试，检查退出码和引擎错误。新增检查覆盖真实输入到伤害的时间、骨骼加载、回锋路径命中与终点、无效施法、实际撞墙伤害、击退、架势追斩和飞弹反射。

`play_stillwater.gd` 自动控制移动、攻击、技能、闪避与追斩，不修改生命值、不跳过敌人。本轮原生 Metal 自动操控跑完三处封印和首领，击败 19 名敌人；其结果仅为回归检查，不代表真人平衡结论。`capture_duel_3d.gd` 是脚本操控的首领演示，原生渲染视频位于 `output/rebirth/Stillwater-combat.mp4`；固定帧率录制不是性能基准。

构建位于 `output/releases`。macOS 在当前机器启动验证；Windows 为交叉导出，未完成 Windows 实机测试。尚未公证或公开发布。

## 设计参考和边界

参考开发者对 [Sifu 架势与借势战斗](https://blog.playstation.com/2021/11/18/how-sifus-kung-fu-combat-works/) 的说明：防守应制造机会，环境和敌人之间应有相互作用。本项目据此实现留影回锋和破阵碰撞，未复刻其完整系统。

这是单地图短篇关卡。角色仍为通用授权模型；尚缺专属角色美术、多章节内容、真人试玩迭代和跨硬件认证。通过回归检查不等于已达到商业作品的完成度。

## 动作回归修复

修复手动采样动作与计时混合冲突：旧代码 `play(clip, 0.025)` 后只执行 `seek` 和 `advance(0)`，混合权重无法推进，九组攻击的手臂变化仅约 0–0.014 弧度。采样动作改为零时长切换，并按各段动画实际挥砍位置分别重映射时间。新增测试同时要求姿势离开待机、攻击过程中持续变化，避免仅检查伤害而漏掉静止角色。

移除留影到玩家的持续牵线和回锋时的直线光束；回锋改为横斩动作。剑轨改用平滑、两端收细和逐点透明的细弧。近景检查脚本为 `scripts/tools/capture_attack_review.gd`，仅录像检查时收近镜头，并屏蔽实体按键干扰。

## 控制与读招修订

命中停顿只暂停动作时钟，输入、移动与防御仍会处理。玩家主动命中停顿缩短至 12 毫秒；重刃、直剑与灵剑各自检查实际体力成本，不再在体力不足时静默拒绝出剑。键盘格挡保持当前朝向，不再被闲置鼠标位置带偏。

常规移动使用更强的松手制动，测试余移约 0.087 米；闪避结束速度限制为 2 米/秒并快速收步，防止 17 米/秒的闪避速度进入普通移动。步行动画按实际移动速度播放。

普通敌人不再使用膨胀地圈。举刃蓄势、短暂停留、接触前 160 毫秒的兵刃亮点和下劈组成读招；首领真实范围招式仍保留范围边界。普通攻击收窄至锁定方向约 99 度，侧移出刀路可避开命中。受击打断当前攻击并播放后仰，屏幕边缘短暂变色，角色附近显示伤害来源方向与扣血；成功防守有独立挡击动作与声音。

`test_control_readability.gd` 验证松手制动、闪避收步、命中停顿期间移动、受击状态和方向反馈、取消扩圈、刃光时机、侧移避击、正面命中与体力拒绝提示。`capture_readability.gd` 在正常战斗镜头下录制真实蓄势、受击和防守，输出为 `output/rebirth/Stillwater-readability.mp4`。
