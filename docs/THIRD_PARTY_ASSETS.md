# Third-party assets

## KayKit Character Pack — Adventurers 1.0

- Author: Kay Lousberg / KayKit
- Official source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
- Files: `assets/characters/kaykit/{Rogue_Hooded,Knight,Mage}.glb`
- License: CC0 1.0. Original license retained at `assets/characters/kaykit/LICENSE.txt`.
- Original GLBs and embedded textures are unchanged. Runtime code changes cloth palettes, head proportions, animation timing and equipped weapons. These are licensed third-party characters, not bespoke character sculpts made for this project.

Noto fonts retain their OFL license in `assets/fonts`. Earlier 2D source art and its records remain in `docs/ART_V2.md`.

Combat WAV files in `assets/audio/combat` are generated by the project's `scripts/tools/compose_combat_audio.py`; no external sound samples are used.

## 剑意更新音效

`assets/audio/combat/{ui,ready,seal,surge,boss,victory}.wav` 由项目内 `scripts/tools/synthesize_ritual_audio.py` 的确定性振荡器与噪声合成生成，未使用外部录音。`StillwaterSans.tres` 与 `StillwaterSerif.tres` 是现有 OFL Noto 字体的字重实例，字体源文件与授权保留。
