# 青岚一夜 · 重构记录

日期：2026-09-05。引擎：Godot 4.6.2。

## 本轮交付

- 新开场、美术背景、指南、设置、战斗 HUD、行囊、成长选择、暂停和胜败结算。统一墨青、玉色、暖金与中文字体。
- 村庄地表与树木、岩石、箱子重绘，保留房屋和原角色的跑步、待机素材；夜间月光、灯笼与萤火层级调整。
- 攻击人物改为独立的三方向六帧动作，运行时兵刃按手部位置绘制；准备、出手、收势分离，伤害发生在出手时刻，闪避取消未释放攻击。
- 青锋剑、玄铁重刃、流萤灵剑分别提供均衡、重击和快速低耗节奏；连击、体力、防御反击、冲刺免伤、受伤保护继续保留。
- 五种技能分别为唤灵、神光、月牙斩、玉风暴、回春。月牙斩实际飞行并被障碍阻挡；范围攻击和治疗具有独立表现。失败施法不扣体力、不进入冷却。
- 击败 6、14 名敌人时暂停选择成长，24 名后进入山君首领战。首领拥有定向冲锋与范围震击预警、收招窗口；击败首领才胜利。
- 新增原创程序合成夜曲，音量和震屏设置持久化，保留本地最佳记录。

## 验证

27 个测试脚本全部通过，包含新增兵刃出手/闪避取消和首领预警测试。测试覆盖输入、碰撞、技能代价、复活规则、库存、阶段选择、首领出现与胜利停止攻击。完整战役的整合测试使用受控击杀推进，不等同于真人完整通关或长期平衡测试。

原生 Metal 渲染截取标题、日夜、行囊、暂停、挥刀、成长、首领和结算画面，输出 `output/art-v2/`。截图由引擎视口读取，HDR 图像先转 sRGB。绿色背景原图保留，透明图与派生动作图通过四角透明和有效覆盖率检查。

macOS Universal 可运行包：`output/releases/Moonlit-Jianghu-macOS.zip`。已验证脱离编辑器的原生启动。正常关窗增加音频停止与延迟清理；`--quit-after` 强制退出仍可产生引擎 AudioStreamWAV 释放警告。本地导出，不包含公开发布或 Apple 公证。

## 当前边界

这是具有完整胜败流程的单地图动作关卡。仍需真人长时间试玩来判断难度曲线和重复游玩价值；首领采用单张美术配合程序动作，尚无完整逐帧跑动动画。没有多地图剧情或经过广泛硬件验证的商业版本。界面与战斗重构已落地，“优秀”仍需实际玩家验证。
