# 雨歇 · 当前游戏设计

更新：2026-09-06。当前主线为 Godot 4.6.2 的 3D 武侠动作篇章。

## 体验目标

在单座山门庭院中，通过敌人蓄势与兵刃提示判断时机，用侧移、见切、闪避留影回锋和破阵碰撞制造反击机会。控制与反馈应让玩家明确知道行动是否执行、危险来自哪里、为何命中或落空。

## 已实现

三种兵刃、骨骼动作、输入缓冲、短距离收步、方向判定、受击反馈、留影回锋、破阵与碰撞、飞弹反射、架势追斩；三座石灯、两次成长、首领第二阶段，以及标题、指南、暂停和结算。
