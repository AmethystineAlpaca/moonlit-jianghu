# 月下江湖 · 青岚一夜

一个用 Godot 4 制作的俯视角武侠动作游戏。守住青岚村，选择战中成长，迎战山君。

![开场](docs/showcase/v2/01-title.png)

## 新版本

- 完整开场、指南、设置、行囊、战斗界面和胜败结算。
- 三种可切换兵刃，独立攻击动作、准备与收招，连击、格挡反击、闪避与体力管理。
- 五种技能：唤灵、神光、月牙斩、玉风暴、回春。
- 两次成长选择，三阶段遭遇，最终山君首领战。
- 重绘地面和场景物件、中文字体、夜间光影与原创合成音乐。

![山君现世](docs/showcase/v2/10-mountain-guardian.png)

本轮为单地图完整关卡，重构内容和验证边界见 [重构记录](docs/POLISH.md)，素材来源见 [素材记录](docs/ART_V2.md)。

本地 macOS 安装包位于 `output/releases/Moonlit-Jianghu-macOS.zip`。解压后运行应用；项目也可直接用 Godot 4.6.2 打开。

## 操作

- 移动：`WASD` 或方向键
- 攻击：`J` 或鼠标左键，按住连续攻击；鼠标攻击朝向指针；三段连击最后一击强化
- 防御：`K`
- 冲刺：`L` 或 `Shift`，冲刺期间免伤
- 使用当前技能：`Space`
- 选择并施放技能：`1`-`5`；`Space` 再次施放当前技能
- 背包：`M`
- 切换白天/夜晚：`P`
- 重置场景：`R`
- 暂停和设置：`Esc`，可关闭震屏或游戏声音，设置自动保存

## 本地运行

需要 Godot `4.6.2`。

```bash
godot --path .
```

## 2026-09 整体打磨

加入三连击、180ms 攻击缓冲、冲刺残影、受击保护、伤害数字和敌人蓄力预警。角色跑步使用已有的对齐透明图集，保留所有源图。地图降低随机物件密度、保留十字通路，并修复一处固定树木重叠；场景加入克制的地表调色、月光和屋前暖灯。

五个技能分别为转化、护体神光、月牙斩、玉风暴和回春。后三个技能有体力消耗和独立冷却，攻击技能检查遮挡；治疗失败不扣体力。数字键直接施放，空格重复当前技能。

守村目标是击败 24 个敌人，每 6 个恢复 1 点生命并补满体力。完成后停止敌人进攻，显示结算和重开按钮；最高击败数保存在本地。暂停菜单提供音效和震屏开关。

验证详情见 [打磨记录](docs/POLISH.md)。这仍是单地图动作游戏，尚未包含完整剧情、多关卡战役和经过长期试玩的难度曲线。
